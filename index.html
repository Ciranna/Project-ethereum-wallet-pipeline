Ethereum Wallet Pipeline

From Mnemonic Phrase to Ethereum Address

An interactive educational exploration of wallet standards and cryptographic primitives.

1. Wallet Recovery Phrase

Explore how BIP-39 converts a mnemonic phrase into a deterministic seed.

Educational test vectors only. Never enter a real wallet recovery phrase.

2. Wallet Pipeline

Mnemonic → BIP-39 → Seed

Seed → BIP-32 / BIP-44 → Private Key

Private Key → secp256k1 → Public Key

Public Key → Keccak-256 → Address

Address → EIP-55 → Checksummed Address
