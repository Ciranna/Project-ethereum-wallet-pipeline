Step 1 — BIP-39

Mnemonic → Seed

Ready
How does BIP-39 work?

BIP-39 derives a 512-bit seed from a mnemonic phrase and an optional passphrase.

It uses PBKDF2 with HMAC-SHA512, 2048 iterations and Unicode NFKD normalization.

Seed = PBKDF2-HMAC-SHA512( mnemonic, "mnemonic" + passphrase )

The resulting seed is 64 bytes long.

Educational test vectors only. Never enter a real wallet recovery phrase.

How does hierarchical derivation work?

BIP-32 derives a master private key and chain code from the seed using HMAC-SHA512.

I = HMAC-SHA512("Bitcoin seed", seed)

The left 32 bytes form the master private key, while the right 32 bytes form the chain code.

BIP-44 defines the hierarchical derivation path used to select the Ethereum account key.

m/44'/60'/0'/0/0

Step 3 — secp256k1

Private Key → Public Key

Locked
How does elliptic-curve cryptography work?

The public key is generated by elliptic-curve scalar multiplication.

Q = k × G

k is the private key, G is the generator point, and Q is the resulting public key.

Ethereum uses the secp256k1 elliptic curve. Recovering k from Q is computationally infeasible with currently known classical algorithms at the security level of this curve.

Step 4 — Keccak-256

Public Key → Ethereum Address

Locked
How is an Ethereum address generated?

Ethereum hashes the 64-byte public key using Keccak-256.

Hash = Keccak256(PublicKey)

The Ethereum address is obtained by taking the last 20 bytes of the 32-byte hash.

Address = Hash[12..31]

Keccak-256 is distinct from the standardized SHA3-256 function.

Step 5 — EIP-55

Locked
How does the EIP-55 checksum work?

EIP-55 introduces mixed-case hexadecimal encoding to help detect typing errors.

A Keccak-256 hash of the lowercase hexadecimal address text determines which letters are capitalized.

The checksum does not change the underlying 20-byte Ethereum address.
